# Real-record workspace

The primary task is to import operational facts and review a feasible allocation.
Keep that sequence visible and carry the existing Pulp Riot purple/pink identity
into a quiet workspace: ink #242638, purple #6652bd, pink #d95878, green #19866d,
canvas #f7f8fc, lines #e5e6ee. Segoe UI provides a locally available UI face.
Use left-aligned text, generous form spacing, and denser evidence tables.

Layout: persistent navigation | title and stream state | working form/evidence.
Import is a two-column form and field contract; plans expand into allocations and
constraints. Charts show only imported positions and routes. The subject-specific
element is the ordered source-to-approval workflow, not a decorative hero.

Review: an initial generic metric-heavy landing was unnecessary for an import
task, so the opening screen is the source form with a short four-step path. Metrics
belong in the live board. Empty charts explain the required imports. Service names
are restricted to diagnostics and model evidence; the workflow uses plain language.
