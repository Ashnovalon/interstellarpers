Your real-records workflow

Validate JSON/CSV → import → CDC event stream → validated live state → forecasts and scenario comparisons → constrained allocation → human approval → durable dispatch request.

Next.js, TypeScript and ECharts provide the workspace. FastAPI, Kafka, Debezium, Flink, PostgreSQL, Redis, object storage with Iceberg, ClickHouse, XGBoost, MLflow, Airflow, OR-Tools, Ray and Temporal run as local services. Docker, Kubernetes manifests and OpenTelemetry, Prometheus and Grafana configuration are included.

No company records are preloaded. Existing synthetic scenarios remain in their original database.
